====== JSON Data Benchmark Testing ======


===== PHP Stopwatch =====
[[https://www.dokuwiki.org/plugin:stopwatch|Stopwatch plugin]] measures execution time of PHP code:
  * ''%%<stopwatch reset>%%'' - Resets stopwatch to zero.
  * ''%%<stopwatch show>%%'' - Show elapsed time in seconds since last reset.


===== Recursive JSON load =====
Here is JSON data with src attribute, which links to itself. So it is recursively loaded 30 times.
<code>
<stopwatch reset>
<json id=cookie path=cookie src=benchmark#cookie display=combined,log*>
{
  "name": "Butter cookie",
  "type": "cookie",
  "Ingredients": {
    "eggs": "3",
    "flour": "500 g",
    "sugar": "300 g",
    "butter": "250 g"
  }
}
</json>
Time elapsed: <stopwatch show>
</code>

===== Load multiple files into JSON array =====
Here is one long JSON file with random data: [[.1000files:file1]]. For testing purposes it should be copied to different filenames 1000 times. Here is bash command for this:
<code bash>for i in {2..1000}; do cp file1.txt "file$i.txt"; done</code>

==== Load one file ====
<stopwatch reset>
<json path=stack1[] src=.1000files:file1 display=combined,log*></json>
''%%<json path=stack1[] src=.1000files:file1 display=combined,log*></json>%%''\\
Time elapsed: <stopwatch show>
