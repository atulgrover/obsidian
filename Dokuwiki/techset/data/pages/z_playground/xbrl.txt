## **Open-Source Tools**

| Tool | License | Key Features | Notes |
| **Arelle** ([arelle.org](https://arelle.org)) | Apache 2.0 | Full XBRL processor (parse, validate, render, API access). | Core engine used by regulators (SEC, CIPC, MCA). Ideal backend for your platform. |
| **tidyxbrl** ([PyPI](https://pypi.org/project/tidyxbrl/)) | MIT | Converts XBRL to “tidy” pandas DataFrames. | Great for Python-based audit analytics. |
| **XULE** ([xbrl.us](https://xbrl.us/home/priorities/use/what-is-xule/)) | Apache 2.0 | Rule-based extraction and validation. | Useful for audit/compliance logic. |
| **XBRLAPI** ([GitHub](https://github.com/xbrlapi/xbrlapi)) | Apache 2.0 | Java-based API for querying and analyzing XBRL data. | For enterprise-grade integration. |
| **Frontegg + Arelle combo** | OSS (partial) | Build secure dashboards (React + FastAPI) with Arelle backend. | Best for your multi-user SaaS setup. |

**custom, AI-powered audit platform**:

* Use **Arelle + PostgreSQL + FastAPI** as your data engine.
* Layer **tidyxbrl** for extraction + **XULE** for rule validation.
* Add an **LLM/RAG interface** (LlamaIndex or LightRAG) for Q&A on financial data.
* Frontend: **Streamlit** (for dashboards) or **React** (for multi-user web app).
