# ✅ **1. Standard Instruction Format (Alpaca-style JSONL)**

```
{"instruction": "Summarize the claim", 
 "input": "Creditor ABC claims ₹5 crore unpaid invoices.", 
 "output": "ABC claims ₹5 crore for unpaid operational dues."}
```

Variations:

### **No input field**

```
{"instruction": "Define insolvency resolution process", 
 "output": "It is a time-bound mechanism under IBC..."}
```

### **With context block**

```
{"instruction": "Identify type of creditor", 
 "input": "XYZ Bank has a secured loan of ₹20 crore.", 
 "context": "IBC Section 5(7)", 
 "output": "Financial creditor"}
```

---

# ✅ **2. Chat Format (ShareGPT / OpenChat)**

```
{"messages": [
    {"role": "system", "content": "You are an insolvency lawyer assistant."},
    {"role": "user", "content": "Explain Form B."},
    {"role": "assistant", "content": "Form B is used by operational creditors..."}
]}
```

Variations:

### **User–Assistant only**

```
{"messages": [
    {"role": "user", "content": "What is the moratorium?"}, 
    {"role": "assistant", "content": "A moratorium prohibits..."}
]}
```

### **Multi-turn**

```
{"messages": [
    {"role": "user", "content": "Who files Section 7?"},
    {"role": "assistant", "content": "A financial creditor."},
    {"role": "user", "content": "Evidence required?"},
    {"role": "assistant", "content": "Loan documents, default proof..."}
]}
```

---

# ✅ **3. Completion Format (GPT-J / Pythia Style)**

```
{"prompt": "Draft a claim acknowledgment letter:\n", 
 "completion": "Dear Creditor,\nWe acknowledge receipt..."}
```

Variations:

### **With separator token**

```
{"prompt": "Query: classify creditor type\nInput: ABC Ltd supplies raw materials\n### Response:", 
 "completion": "Operational Creditor"}
```

---

# ✅ **4. Self-Instruct (Prompt → Target)**

```
{"prompt": "Identify default date from the data: ...", 
 "target": "Default occurred on 15 June 2021."}
```

---

# ✅ **5. RAG / Retrieval Format**

### **Query → Relevant chunks**

```
{"query": "What is the CIRP timeline?", 
 "docs": ["Section 12: 180 days + 90 days..."], 
 "answer": "The CIRP must be completed within 180 days..."}
```

### **Q&A Pairs**

```
{"question": "Who can file Section 9?", 
 "answer": "Operational creditors."}
```

---

# ✅ **6. Classification Format**

### **Labelled**

```
{"text": "ABC Ltd supplied goods worth 5 crore unpaid", 
 "label": "Operational Creditor"}
```

### **Multiple labels**

```
{"text": "XYZ Bank term loan 20 crore", 
 "labels": ["Financial Creditor","Secured"]}
```

### **Multi-class**

```
{"input": "Delay of 600 days in filing claim", 
 "class": "Late Claim"}
```

---

# ✅ **7. Embedding Training Format (Nomic / Sentence Transformers)**

### **Pairs**

```
{"text_1": "Operational creditor", 
 "text_2": "Supplier claiming unpaid operational dues", 
 "label": 1}
```

### **Triplets**

```
{"anchor": "Secured financial creditor", 
 "positive": "Bank with exclusive charge", 
 "negative": "Employee salary claim"}
```

---

# ✅ **8. Reinforcement Learning (RLHF / DPO)**

### **Preference pairs**

```
{"prompt": "Draft Section 7 petition",
 "chosen": "A clear structured petition...",
 "rejected": "A vague low-quality draft..."}
```

### **DPO style**

```
{"prompt": "Explain CoC voting", 
 "chosen": "Approval requires 66%", 
 "rejected": "CoC majority is 51%"}
```

---

# ✅ **9. Multi-modal (Text + Metadata)**

### **With metadata fields**

```
{"text": "XYZ Bank holds 20 crore secured debt.", 
 "meta": {"type": "financial", "section": "5(7)"}, 
 "label": "Financial Creditor"}
```

---

# ✅ **10. Tabular → Text (for Banks, Claims, Valuation)**

```
{"row": {"creditor":"ABC Ltd","claim":50000000,"type":"operational"}, 
 "output": "ABC Ltd claims ₹5 crore as an operational creditor."}
```
